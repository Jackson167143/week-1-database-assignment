# Week 1 Database Assignment

## Hospital Management System

This project is a MySQL database created for a Hospital Management System.

## Database Name

hospital_management

## Tables

- patients - Stores patient information.
- doctors - Stores doctor information.
- appointments - Stores appointments between patients and doctors.

## Technologies Used

- MySQL
- SQL
- GitHub

## Files

- answer.sql
- README.md

## How to Run

1. Open MySQL.
2. Open the answer.sql file.
3. Run the SQL code.
4. The hospital_management database will be created.
5. The tables and sample data will be added.
